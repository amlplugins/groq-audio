# @amlplugins/groq-audio

Native `groq-sdk` SDK re-exported under the `@amlplugins` namespace.

> Groq Audio — Whisper Large v3 transcription/translation and PlayAI TTS at high throughput.

## Install

```bash
npm install @amlplugins/groq-audio
```

## Use

```ts
import { /* named exports from groq-sdk */ } from "@amlplugins/groq-audio";
// or
import sdk from "@amlplugins/groq-audio";
```

Built and published by GitHub Actions on every push to `main`.

Part of the amlplugins family — see https://github.com/amlplugins.
